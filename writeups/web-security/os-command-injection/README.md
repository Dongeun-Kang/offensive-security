# OS Command Injection

OS command injection, also known as **shell injection**, is a vulnerability that allows an attacker to execute operating system commands on the server hosting an application.

If successfully exploited, it can lead to full compromise of the application and its data. In some cases, an attacker may also use the compromised server to access other parts of the hosting infrastructure, abuse existing trust relationships, and pivot to additional systems within the organisation.
