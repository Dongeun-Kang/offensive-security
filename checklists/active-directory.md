# Active Directory Checklist

## Scope

- Confirm authorization and target boundaries.
- Record environment, URLs, hosts, ports, and credentials provided for the lab.

## Enumeration

- Identify exposed services and application entry points.
- Capture versions, headers, banners, and unusual behavior.
- Save relevant screenshots or command output under `assets/`.

## Findings

- Document the weakness, impact, proof, and remediation notes.
- Link related writeups, references, and external reading.

## Cleanup

- Remove temporary files from the lab target when applicable.
- Record lessons learned and follow-up topics.
